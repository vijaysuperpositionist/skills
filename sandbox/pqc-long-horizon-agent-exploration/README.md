# PQC Long-Horizon Agent Exploration (Sandbox)

Experimental notes, not a shipped skill or committed product direction.

This folder holds a technical exploration document derived from a recorded
conversation between Vijay (Vyapti Resonance) and Indu about whether a
long-horizon AI agent could meaningfully assist with post-quantum
cryptography (PQC) migration — investigating a real codebase, proposing a
bounded change, testing it, and producing before/after evidence, rather than
just producing a one-shot scan report.

Karan asked Vijay to share the conclusion/thinking from that discussion so
Utopia has enough real technical context to run an independent experiment
with Factory AI (Long Horizon Agents). This is that write-up.

**What this is:** a faithful extraction of what was actually discussed, with
explicit hypothesis and open-question sections, intended as a starting point
for Utopia's own Factory AI experiment.

**What this is not:** a product specification, an architecture commitment, a
claim about Factory AI's actual capabilities, or a claim that any agent can
safely modify production systems.

See [`LONG_HORIZON_AGENT_PQC_EXPLORATION.md`](./LONG_HORIZON_AGENT_PQC_EXPLORATION.md)
for the full document.

This is sandboxed, isolated content — it does not touch, reference, or
depend on any existing skill, pack, or module in this repository.
